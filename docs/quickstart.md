# Quickstart

The core library (gate, coverage map, retriever, guardrails, and the
reference provider/store/embedder implementations) works today — see the
example in the [README](../README.md#status). There is no CLI yet
(`rag-gate init/ingest/ask` land in Phase 2), so using the library today
means writing a small Python script like the one in the README, not
running a single command.

This page will become the real two-minute, CLI-driven quickstart once
Phase 2 lands. Until then, [`docs/architecture.md`](architecture.md) and
the [ADRs](adr/) are the best map of what exists and why.
